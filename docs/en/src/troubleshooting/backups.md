# Twine RS desktop backups

This compatibility manual does not define Twine RS backup or recovery
behavior.

See the canonical
[Twine RS desktop recovery and backups guide](https://github.com/twine-rs-labs/twine.rs/blob/main/docs/user/recovery-and-backups.md)
for current defaults, retention behavior, project-data boundaries, and folder
safety warnings.

Upstream Twine browser storage and recovery are separate from Twine RS desktop
behavior.
