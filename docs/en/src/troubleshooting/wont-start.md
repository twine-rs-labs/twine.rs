# Twine RS desktop startup recovery

The inherited Twine recovery instructions previously on this page did not
describe Twine RS storage and could put project data at risk.

See the canonical
[Twine RS desktop recovery and backups guide](https://github.com/twine-rs-labs/twine.rs/blob/main/docs/user/recovery-and-backups.md)
for reversible settings-reset steps and current storage boundaries.

Upstream Twine is a separate product. Do not apply Twine RS recovery steps to
its application-data or story directories.
