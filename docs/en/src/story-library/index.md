# Using the Story Library

When you first open twine.rs, it'll show you the _Projects_ screen. This is the
project launcher and the home of your story library. It lets you create, import,
find, organize, open, duplicate, and delete projects.

The actions on the left create a [_New Project_](creating.md), import an
existing story or project folder, and export a restorable archive of the entire
library. The rest of the screen can show the library as a table or as cards.

In the desktop app, new and imported stories are normally backed by visible
[project folders](location.md). In the web app, projects are saved in the
current browser. The launcher shows a storage reminder and an _Export Backup_
action when browser storage is in use.
