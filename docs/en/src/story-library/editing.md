# Editing Stories

To start editing a story, double-click its row or card on the _Projects_ screen,
or choose its _Open_ button. Twine opens the story in the workbench using its
remembered Text, Graph, or Split mode.

The current application window edits one story at a time. Use _Stories_ in the
workspace rail to return to the launcher and open another.

In the web app, avoid editing the same browser-local project in multiple tabs.
The tabs do not coordinate their in-memory changes and one can overwrite work
from another.

Desktop project folders can also be edited with external tools. Twine watches
open folders and applies nonconflicting disk changes. See
[Reviewing External Changes](conflicts.md) before combining both workflows.
