# Uninstalling Twine RS

Preserve and verify your work before removing anything. Application files,
project folders, backups, and settings are separate data. Uninstalling the app
is not a backup or recovery operation.

## Desktop

Quit Twine RS. On macOS, remove the installed **Twine RS.app** from Applications.
On Windows, use the installed Twine RS uninstaller from system app settings or
the Start menu. On Linux, remove the AppImage or dedicated extracted application
directory; if you installed through another package system, use its removal
process. These steps remove the application, not an instruction to erase your
stories or settings.

Keep the library, backups, separately stored `.twine.rs` projects, and settings
unless you separately choose to delete verified copies. Confirm their actual
locations using [recovery and backups](../troubleshooting/backups.md) and
[startup settings recovery](../troubleshooting/wont-start.md); do not remove an
upstream Twine directory by mistake. Removing the app does not make it safe to
assume all project data have been erased.

## Browser

Export your library and preserve external assets first. Verify the export in
a separate browser profile. Clearing site data destroys the browser-local
library for the exact editor origin and profile. Identify that origin from the
address bar; `twinery.org` is a separate product, not a universal Twine RS
storage location. Read [browser storage preservation](../troubleshooting/local-storage.md)
before deliberately removing site data.
