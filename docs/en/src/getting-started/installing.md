# Twine RS availability and source setup

This compatibility manual does not provide installation instructions for Twine
RS. No formal downloadable Twine RS release has yet been published.

See the canonical
[Twine RS availability and updates guide](https://github.com/twine-rs-labs/twine.rs/blob/main/docs/user/availability-and-updates.md)
for current source setup and shipped distribution behavior.

Upstream Twine is a separate product. Its browser service and downloadable
installers are not Twine RS distribution options.
