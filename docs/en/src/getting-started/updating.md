# Updating Twine RS

Current Twine RS builds have no operated update metadata feed. Automatic
updates are unavailable. **Check for Updates** reports that update checking is
unavailable when no feed is configured; it does not establish that your version
is the newest.

Check [Twine RS Releases](https://github.com/twine-rs-labs/twine.rs/releases)
manually. Read the chosen release's changes, compatibility requirements, and
rollback guidance. Preserve your library, separately stored project folders,
and settings before replacing the app. Then follow the
[installation steps](installing.md) and verify a disposable copy of your work.

For source builds, use the selected tag's own
[build instructions](https://github.com/twine-rs-labs/twine.rs/blob/main/README.md).
Preserve local changes and browser exports before replacing a checkout or web
build. Test a different build in a separate browser profile or origin first.
See [rollback](downgrading.md) when returning to an earlier version.

Upstream Twine versions and update services do not describe Twine RS.
