# Changing the Default Story Format

On the [_Story Formats_ screen](viewing.md), select a format and choose _Use as
Default_. Its card receives a _Default_ badge and the button becomes disabled.
You can also choose the default format from the _Story Formats_ panel in
[Settings](../customizing/preferences.md).

Changing the default story format doesn't affect stories you've already created,
only new ones you create in the future. You [can change the story format for
existing stories](../editing-stories/changing-story-format.md) in the Story Map
or workbench.
