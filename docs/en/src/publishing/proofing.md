# Proofing a Story

Proofing a story uses a special story format that is designed to make
proofreading and copyediting the text of your passages easier.

Open _Build & Export_, switch to _Preview_, choose a _Proofing format_, and
choose _Proof_. You can also use _Proof_ in the workbench's _Build_ action tab
or run _Proof Story_ from the command palette. Those quick actions use the
default proofing format from Settings.

If no installed format declares proofing support, Twine offers the current
story format or another loaded format as a fallback. You can set the
application default in [Settings](../customizing/preferences.md) or from the
[_Story Formats_ screen](../story-formats/proofing.md).

Proof output is temporary. Use an exported file when you need a durable copy.
