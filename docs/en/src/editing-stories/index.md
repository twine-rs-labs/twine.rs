# Editing Stories

Opening a project takes you to the workbench. Choose **Text** for source
editing, **Graph** for the passage graph, or **Split** for both. Open a passage
to add its editor buffer to the dock.

Use the **Story**, **Passage**, **View**, and **Build** action tabs in the
application header for actions on the current story or selection. The
[interface guide](../getting-started/getting-around.md) explains navigation and
the command palette; [graph navigation](navigating.md) explains selection,
zoom, and pan.
