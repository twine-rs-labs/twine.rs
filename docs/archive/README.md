# Documentation archive

Status: historical material

Files here preserve research, completed implementation plans, release
remediation, and dated audits. They are useful for rationale and provenance but
do not describe current architecture, status, or scheduling.

Use:

- [`../architecture/`](../architecture/overview.md) for the live system;
- [`../status/`](../status/current.md) for current capabilities;
- [`../roadmap/`](../roadmap/README.md) for unfinished work;
- [`../product/`](../product/README.md) for normative behavior.

Archived files should not receive new completion annotations or become targets
for active cross-document status tracking.
